Secure passwords for the rest of us.

Psss is a private password manager for iPhone, iPad and Mac. It keeps your passwords, passkeys, verification codes, cards and notes in one encrypted file that you own.

Join the waitlist

What you get

  • Yours alone

    There is no account to make and no Psss server holding your data. The app has no analytics.

  • One file you own, in an open format

    Everything lives in one encrypted file in the open KeePass format (KDBX). Apps such as KeePassXC and Strongbox can open it, so you can leave whenever you like.

  • Made for Apple devices

    Psss fills sign-ins through the system's own AutoFill on iPhone and iPad, and unlocks with Face ID or Touch ID.

  • Easy to move in

    Bring your passwords from Apple Passwords or 1Password 7, or open the KeePass file you already have where it is.

Questions

Who can read my passwords?

You can. The file is encrypted and opens with your vault password, or with Face ID or Touch ID on your device. We run no server and keep no copy, so we cannot read it and cannot recover it for you. No outside security audit has been done yet; one is planned before version 1.0.

Where is my data?

In a file on your device. Sync through iCloud Drive is coming; when you turn it on, the same encrypted file is kept in your iCloud Drive, and Psss has no server in between.

What if I stop using Psss?

Your passwords are in a standard KeePass file. Open it in KeePassXC, Strongbox or another KeePass app. Nothing is locked in.

What does it cost?

Nothing is decided about pricing yet. Sync through iCloud will be free.
