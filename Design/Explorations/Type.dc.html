Psss · Typography · Rounded sans

Soft letters for a firm promise.

Eight rounded sans-serifs, all set the same way next to the new mark. The serif is gone. Each card shows the lockup, a headline and a line of body copy, so you can judge both the logo and the voice.

The reference. Your starting point. A system font on Mac and in Office, so it needs a commercial licence for web embedding. Shows as plain Arial if it is not installed on your machine.

SF Pro Rounded02
Secure passwords for the rest of us.

The native one. Matches the app’s own interface on Apple devices. Apple’s licence limits it to Apple platforms, so it is not for the logo or the website. Shows a fallback if your machine is not Apple.

Varela Round for the wordmark and headlines, Nunito for longer text on the web. In the app, the system font.
Varela Round is the nearest free match to Arial Rounded, with the same circular, even letters as the p’s bowl. Nunito adds the weights and italics that Varela lacks.
